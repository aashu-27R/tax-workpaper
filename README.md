# Okafor-Lindqvist Tax Workpaper (case study)

Live app: https://aashu-27r.github.io/tax-workpaper/

A web-native tax workpaper. It loads `packet.json` exactly as delivered, then builds an evidence graph from it and keeps every action in an append-only journal.

Write-up: `writeup.pdf`

To try it: open the app, go to Firm › "Load demo season activity", then use "Acting as" to switch roles and "As of" to replay the season.
